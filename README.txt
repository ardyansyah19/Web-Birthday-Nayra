# Birthday Website — Shesya Nayra Oktaviola ❤️

Landing page ulang tahun satu halaman, nuansa Valentine yang elegan.
Tanggal: 03 Oktober 2026

## Cara membuka
Klik dua kali index.html, atau pakai VS Code + ekstensi "Live Server"
(klik kanan index.html -> Open with Live Server).
Saat dibuka, ada layar "Buka hadiahnya" — tombol itu yang memulai lagu
(browser memang melarang lagu autoplay tanpa klik).

## Struktur
birthday_nayra/
├── index.html
├── style.css
├── script.js
├── README.txt
├── images/   foto-01.jpg ... foto-10.jpg
└── song/     selamat-ulang-tahun.mp3

## Mengedit
- Teks ucapan: langsung di index.html.
- Ganti foto: timpa file di images/ dengan nama sama (disarankan persegi, ~1200px).
- Ganti lagu: timpa song/selamat-ulang-tahun.mp3 (atau ubah src pada <audio>).

## Hosting supaya bisa dikirim lewat link
Upload seluruh folder ke Netlify Drop (app.netlify.com/drop) atau GitHub Pages,
lalu kirim link-nya ke pacar kamu.
